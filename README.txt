DIAMOND'S STUDENT POINT - WINDOWS EXE BUILD

1. Create a new GitHub repository.
2. Upload the files/folders in this ZIP.
3. Open Actions.
4. Select "Build Windows EXE".
5. Click "Run workflow".
6. Wait for the workflow to finish.
7. Open the completed run.
8. Download the artifact named "Diamonds-Student-Point-Billing-Windows".
9. Extract it to get Diamonds_Student_Point_Billing.exe.
